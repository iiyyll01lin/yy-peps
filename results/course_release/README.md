# Course release evidence bundle

`receipt.json` is the machine-readable index for the teaching release. Its
schema is `../schemas/course_release_receipt.schema.json`; the operational
checklist is `../../course/RELEASE_CHECKLIST.md`.

The bundle promotes only three kinds of evidence:

- manifest-backed synthetic `course_fast` smokes that validate executable
  image, texture, and SDF paths;
- complete bounded Kodak and texture pilots whose outcomes remain
  **inconclusive** and non-paper-comparable;
- checksum- and schema-validated 512³ provenance for the three public SDF
  assets, which is input evidence rather than a trained-model result.

It promotes no top-level CSV and no paper number. Every top-level
`results/*.csv` remains `legacy-unverified`. `paper_exact` remains blocked by
published protocol omissions and Pitted Stonefish authorization; the receipt
must continue to report zero paper-comparable results.
